**

- Core Concept: A nostalgic yet enhanced Metin2-like MMORPG with Warframe elements like modular gear, mission-based gameplay, and deep progression.
    
- Art Style: Slightly better than Metin2 but keeping an “old-school” feel for nostalgia.
    
- Core Gameplay Loop: Grind-focused, solo-play friendly, with the option for NPC or Squad Support.
    
- Primary Influence: Metin2 (structure, combat) + Warframe (fluid systems, modularity, mission structure
    
- Core Fantasy:
    
- → The player enters the BCU (Borakel Cinematic Universe), a reality shaped by:
    
- → Certainty: represented by the Boracle
    
- → Uncertainty: represented by unstable forces and beings
    
- → Logos.exe: the universe itself / cosmic system
    

The player’s journey is about exploring, fighting instability, and eventually becoming an advocate of Certainty.
