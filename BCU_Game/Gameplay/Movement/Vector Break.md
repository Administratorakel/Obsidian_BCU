### Shield Core / Vector Break

- Core provides elemental/status enhancement
- Shield adds effects around the weapon's Vector Break
- Vector Break costs Stability
- Cost is percentage-based
- Each weapon type can have a different cost
- Insufficient Stability → Vector Break doesn't activate
- Shield Core status effects (elemental and physical enhancements for VB)
- Vector Break UI (2 stacks visible on screen replacing dash) 
- Core adds visual effects to the animation of element

## Melee encounter landing rule
When a **melee weapon is equipped**, if Vector Break hits an enemy and the player releases all directional input, the player ends **behind the target at maximum melee attack range**, provided the original dash would have overshot that position. This is an intentional landing-assist behavior.



Vector Break is unlocked by spending an ability point to the ability.

After unlocking Vector Break the dash icon will be replaced with the Vector Break Icon, if the player has enough Stability
