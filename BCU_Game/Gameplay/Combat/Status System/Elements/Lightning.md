# Lightning — Elemental Status

**Identity:** Support and tempo  
**Category:** Elemental  
**Maximum building stacks:** 6  
**Base stack duration:** 5 seconds (shared timer for an incomplete set)

## Stack Progression

| Stacks | Effect |
| --- | --- |
| 1–2 | Small Lightning damage per hit. |
| 3 | Small Lightning damage and a **0.5-second stun**. |
| 4–5 | Moderate Lightning damage per hit. |
| 6 | **Lightning Discharge:** a **1-second stun** on the target and a party Attack Speed / Animation Speed buff lasting **5 seconds**. |

## Full-Stack Resolution

- At 6 stacks, check for an eligible allied combination **first**.
- If no combination is available, **Lightning Discharge** activates immediately.
- One **highlighted completed set** of 6 stacks stays available for allied combinations for **5 seconds**. Its expiration cannot be extended by subsequent Lightning applications.
- During this time, a **separate building set** can accumulate new Lightning stacks, shown by the smaller indicator.
- There can be **only one completed Lightning set per player per enemy**.
- If the building set reaches 6 before the highlighted set expires, its new Discharge triggers, replacing the old highlighted set and starting a fresh 5-second completed-set timer.
- Every new Discharge stuns the enemy immediately for 1 second.
- A new Discharge's 5-second party buff **replaces** the previous Lightning buff; the buffs do **not** stack in strength.
- If a combination consumes the completed set early, the party buff still lasts for its original 5 seconds unless superseded by a new buff.
- If no combination consumes the completed set, it disappears after its 5-second window.
