# Burned Wounds — Status Combination

**Identity:** Status-application vulnerability  
**Combination:** [[Fire]] + [[Slash]]  
**Category:** Elemental + Physical  
**Trigger:** Both contributing statuses reach 6 stacks  
**Consumption:** Undecided

## Core Mechanics

- Fire burns wounds opened by Slash, leaving the affected enemy more vulnerable to further status application.
- Subsequent attacks against the affected target have increased **Status Chance**.
- The effect supports status-focused combat and allied follow-up attacks.

## Timing and Status Interactions

- Burned Wounds may coexist with other Slash combinations, including [[Frozen Wounds]] and [[Viral Wounds]], subject to which underlying stacks have already been consumed.
- This status improves **application chance**, not automatically damage dealt.

## Undecided

- Status Chance bonus, effect duration, whether repeated activation stacks, and interactions with status resistance.
- Whether Fire and Slash stacks are consumed or preserved.

## Shared System Rules

## Activation and Ownership

- The system checks for an eligible combination when a compatible status reaches its full-stack threshold, **before** resolving that status's standalone sixth-stack payoff.
- Only the player's own stacks and eligible **allied** players' stacks can contribute. Non-allied players cannot combine stacks with one another.
- Activation is automatic when the requirements are satisfied; it does not need a separate button press.
- When two allied players supply a combination, damage credit is split **50/50** between them.
- If multiple combinations compete for the same stacks, the first eligible pair to complete resolves first. Truly simultaneous event ordering has not been finalized.
