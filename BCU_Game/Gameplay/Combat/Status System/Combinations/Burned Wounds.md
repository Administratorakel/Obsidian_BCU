# Burned Wounds — Status Combination

**Status:** Core concept established; balancing pending  
**Combination:** Fire + Slash  
**Activation:** Both statuses at maximum stacks

## 1. Core Mechanic

Fire burns away the wounds created by Slash, leaving the affected enemy more vulnerable to additional status effects.

While Burned Wounds is active:

- The enemy receives increased vulnerability to **Status Chance**.
- Subsequent attacks have an improved opportunity to apply status effects.
- The interaction is intended to support status-focused combat.

## 2. Combat Identity

Burned Wounds specializes in **status vulnerability**.

Unlike Frozen Wounds, which emphasizes critical hits, or Viral, which increases damage received, Burned Wounds helps players apply additional status effects.

This makes it potentially valuable in multiplayer and status-focused builds.

## 3. Coexistence

Burned Wounds can coexist with other Slash combinations, including Frozen Wounds and Viral.

## 4. Undecided

- Exact Status Chance increase.
- Duration of Burned Wounds.
- Whether Slash and Fire stacks are consumed.
- Whether the effect can stack.
- How Status Chance increases interact with existing resistance mechanics.
