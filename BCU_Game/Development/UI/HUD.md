## 9. UI and Presentation

The following decisions affect the game's presentation:

- Dialogue boxes should appear near the bottom of the screen.
- Dialogue portraits should show expressive character faces.
- The 3D world should use the pixelated art direction.
- The UI's own artistic style remains undecided.
- UI placement requirements should be collected progressively as systems are developed.
- Readability during fast combat should remain a priority when designing the HUD and visual effects.
